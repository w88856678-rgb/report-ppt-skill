# 汇报 PPT Skill · ppt-craft

**把零散资料变成讲得清楚、排版协调、可以继续编辑的 PPT。**

给 Codex 等 AI 助手安装 `ppt-craft`，从文案、大纲或已有演示文稿开始，整理主线、设计页面，再按反馈连续修改。适用于工作汇报、产品介绍、方案说明等需要把信息讲清楚的场景。

[安装技能](#安装) · [开始使用](#三步完成一份演示) · [查看完整工作指引](SKILL.md)

这是可安装的助手技能。实际制作需要宿主具备文件读写、PPT 编辑和预览或渲染能力；请先确认所用 AI 助手支持这些工具。

## 适合谁

| 你的任务 | 可以从哪里开始 |
| --- | --- |
| 资料很多，汇报主线还不清楚 | 提供原始文案或大纲，整理页序和每页重点 |
| 有一份旧 PPT，想更清晰、更协调 | 提供可编辑原稿，沿用已有风格改善字体、对齐和信息密度 |
| 只需要做好一页 | 指定页面和问题，集中调整布局、图示或文字层级 |
| 内容会反复修改 | 以最近认可版本继续调整，保留已经接受的内容与风格 |

## 帮你完成什么

- **理清内容。** 确定整套主线、页序和每页重点，保留事实、单位、数据口径与进展状态。
- **选对表达方式。** 根据内容关系安排对比、流程、层次、图表和图片。
- **统一页面观感。** 协调字体、字重、颜色、对齐和留白，控制文字密度。
- **沿用已有风格。** 从参考稿提取视觉规则，改善拥挤和失衡。
- **接住后续修改。** 按最新反馈调整指定部分，保留此前认可的内容。
- **交付可编辑文件。** 默认交付 `.pptx`，要求检查最终导出文件的内容、排版和对象可编辑性。

## 三步完成一份演示

1. **交材料。** 提供文案、大纲或 PPT，并说明听众、用途、页数和风格要求。
2. **做成稿。** 让助手先理清逻辑，再制作可编辑页面；有参考稿时明确需要保留的风格。
3. **看结果、继续改。** 查看最终文件与预览，指出需要调整的页面或对象，继续在认可版本上修改。

以下是通用请求示例，不含真实业务案例：

```text
请用 $ppt-craft，把我提供的内容做成一套汇报PPT。
先理清逻辑，风格简洁，保留重要数据，交付可编辑的PPTX。
```

```text
请用 $ppt-craft，参考我上传的PPT调整这一页。
保留原文和整体风格，统一字体层级、对齐和间距，让排版更舒展。
```

```text
请用 $ppt-craft，制作一份产品介绍PPT。
面向初次了解产品的听众，突出使用场景和操作流程，不编造效果数据。
```

## 安装

在 Codex 中，将本仓库克隆到技能目录，以 `ppt-craft` 命名：

```bash
git clone https://github.com/w88856678-rgb/report-ppt-skill.git "${CODEX_HOME:-$HOME/.codex}/skills/ppt-craft"
```

如果该目录已经存在，不要覆盖个人改动。也可以下载仓库 ZIP，解压后将技能放入自己的技能目录。安装后的结构应为：

```text
ppt-craft/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── README.md
```

其他支持 `SKILL.md` 的 AI 助手，可按各自的技能安装方式使用，兼容性取决于宿主提供的工具能力。

## 视觉与字体

默认重视清晰的主次关系、克制的强调色和稳定的对齐。包含可选的白底、深色正文、浅色分区方案，也可适配其他品牌风格。

字体优先用同一家族的不同字重建立层级。具体选择取决于运行环境和使用授权，仓库不附带任何字体文件。

## 运行条件与效果边界

本技能提供制作与修改的工作指引。实际制作需要助手具备文件读写、PPT 编辑和预览或渲染能力；图像生成与编辑按任务需要使用相应工具。技能不绑定某个固定的 PPT 库或私有接口，也不会自动安装付费工具。

最终效果受内容量、字体、编辑工具及打开文件的软件影响。技能要求导出后检查最终文件，不承诺所有环境都能完全一致地显示。完整制作与验收要求见 [SKILL.md](SKILL.md)。

## 隐私与素材使用

仓库只包含通用方法与使用说明，不包含真实业务指标、合作方资料、内部链接、原始演示文稿、聊天截图或源文件元数据。

使用时，原始资料留在当前任务的工作目录中，不应加入技能仓库。可编辑对象、图片和字体的使用需遵守各自的授权要求。
