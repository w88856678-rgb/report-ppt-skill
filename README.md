# 汇报 PPT Skill

让 AI 制作逻辑清楚、排版协调、可以继续编辑的 PPT。

技能名称为 `ppt-craft`。支持从文案、大纲或资料开始制作，也支持沿用已有 PPT 的视觉风格、精修单页和连续修改。不限定行业，也不绑定某一种汇报场景。

## 能做什么

- 梳理内容主线、页序和每页重点，保留事实、数据口径与进展状态。
- 根据内容关系安排对比、流程、层次、图表和图片。
- 统一字体、字重、字号、颜色、对齐和留白，控制文字密度。
- 参考已有稿件的优点，保留原稿风格，改善拥挤和失衡。
- 根据后续反馈修改，保留此前认可的内容。
- 优先交付可编辑的 `.pptx`，并检查最终文件的内容、排版和可编辑性。

## 安装

在 Codex 中，可将本仓库克隆到技能目录，以 `ppt-craft` 命名：

```bash
git clone https://github.com/w88856678-rgb/report-ppt-skill.git "${CODEX_HOME:-$HOME/.codex}/skills/ppt-craft"
```

如果该目录已经存在，不要覆盖个人改动。也可以下载仓库 ZIP，解压后将技能放入自己的技能目录。安装后的结构应为：

```text
ppt-craft/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── README.md
```

其他支持 `SKILL.md` 的 AI 助手，可按各自的技能安装方式使用。

## 使用

向 AI 助手提供内容或文件，并说明受众、用途、页数和风格要求。以下是通用指令示例，不含真实业务案例。

```text
请用 $ppt-craft，把我提供的内容做成一套汇报PPT。
先理清逻辑，风格简洁，保留重要数据，交付可编辑的PPTX。
```

```text
请用 $ppt-craft，参考我上传的PPT调整这一页。
保留原文和整体风格，统一字体层级、对齐和间距，让排版更舒展。
```

```text
请用 $ppt-craft，制作一份产品介绍PPT。
面向初次了解产品的听众，突出使用场景和操作流程，不编造效果数据。
```

## 视觉与字体

默认重视清晰的主次关系、克制的强调色和稳定的对齐。包含可选的白底、深色正文、浅色分区方案，也可适配其他品牌风格。

字体优先用同一家族的不同字重建立层级。具体选择取决于运行环境和使用授权，仓库不附带任何字体文件。

## 运行条件

这是给 AI 助手使用的工作指引，不是独立的 PPT 生成软件。实际制作需要助手具备文件读写、PPT 编辑和预览或渲染能力；图像生成与编辑按任务需要使用相应工具。技能不绑定某个固定的 PPT 库或私有接口，也不会自动安装付费工具。

最终效果受内容量、字体、编辑工具及打开文件的软件影响。技能要求导出后检查最终文件，不承诺所有环境都能完全一致地显示。

## 隐私

仓库只包含通用方法与使用说明，不包含真实业务指标、合作方资料、内部链接、原始演示文稿、聊天截图或源文件元数据。

使用时，原始资料留在当前任务的工作目录中，不应加入技能仓库。可编辑对象、图片和字体的使用需遵守各自的授权要求。
